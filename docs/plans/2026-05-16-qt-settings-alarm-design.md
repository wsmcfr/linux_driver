# Qt 参数设置与告警维护界面设计

## 目标

| 项目 | 设计结论 |
|---|---|
| 页面名称 | `参数设置`、`告警维护` |
| 目标屏幕 | STM32MP157 7 寸 RGB LCD，固定 1024x600 |
| 所属程序 | `20_uvc_camera/qt_camera_display/` Qt Quick 工业检测主界面 |
| 核心定位 | 参数页解决现场调试和比赛演示可调问题；告警页解决故障诊断、维护闭环和答辩说明问题 |
| 第一版范围 | 先做 QML 本地状态、触摸交互、摘要提示和模拟维护日志；不声称已经写入真实配置文件或下发 STM32F4 |

## 设计原则

| 原则 | 说明 |
|---|---|
| 工业触屏优先 | 页面保持深色、高对比、高信息密度，触摸目标保持足够高度，避免装饰性大图和低密度排版。 |
| 本地状态先行 | 在真实串口控制器和配置控制器稳定前，参数和告警先作为界面状态存在，方便演示信息架构。 |
| 不冒充硬件闭环 | 参数页的 `应用/保存` 只提示后续路径；告警页的 `清故障` 只模拟界面状态，真实结果必须以后续 F4 状态帧覆盖。 |
| 和既有页面联动 | 参数页复用相机、视频后端、补光、SD/COS 状态；告警页复用手动页急停/回零、统计页上传失败和相机状态。 |
| Overlay 边界清楚 | 进入 `settings` 或 `alarm` 时隐藏 KMS 实时视频 plane，返回首页时恢复，避免视频盖住全屏功能页。 |

## 参数设置页结构

| 区域 | 内容 |
|---|---|
| 页头 | 页面标题、参数摘要、返回首页按钮 |
| 工艺与判定 | 零件类型、良坏阈值、待复核阈值 |
| 视觉定位 | 精定位像素阈值、稳定帧数、像素到脉冲标定 |
| 输送与分拣 | 低速档、分拣超时、F4 限幅说明 |
| 相机光源与存储 | 相机节点、采集参数、视频后端、背光常亮、补光亮度、SD 目录、COS 上传策略 |
| 参数摘要 | 当前参数短摘要、最近操作结果、应用/保存/恢复默认/导出摘要按钮 |

## 告警维护页结构

| 区域 | 内容 |
|---|---|
| 页头 | 页面标题、当前告警摘要、返回首页按钮 |
| 当前告警 | 告警码、名称、等级、发生时间、处理状态、确认/清故障/保存诊断 |
| 设备健康 | 相机、F4 心跳、机械臂、急停、SD 卡、云端、KMS 视频、背光、配置状态 |
| 告警历史 | 最近告警和维护操作，最新在上，可滑动 |
| 处理建议 | 急停/故障恢复的分步骤处理顺序 |

## 状态契约

| 字段/函数 | 用途 |
|---|---|
| `settingsPageVisible` | 控制参数设置页显隐，并参与首页视频/统计区隐藏判断 |
| `alarmPageVisible` | 控制告警维护页显隐，并参与首页视频/统计区隐藏判断 |
| `settingsApplyAction()` | 统一处理应用、保存、恢复默认、导出摘要、上传策略切换、零件切换 |
| `changeSettingValue()` | 统一处理参数加减和范围限制 |
| `alarmHistoryModel` | 保存告警维护页模拟历史记录 |
| `handleAlarmAction()` | 统一处理确认、清故障、刷新状态、保存诊断 |

## 验收方式

| 测试目标 | 执行位置 | 命令/动作 | 预期输出/现象 | 失败时排查 |
|---|---|---|---|---|
| 静态契约 | 本地仓库或虚拟机 | `./test_qt_kms_overlay_assets.sh` | 输出 `PASS: Qt KMS overlay assets contract` | 检查 `settingsPageVisible`、`alarmPageVisible`、页面 `id` 和关键按钮文字。 |
| 参数页入口 | 开发板屏幕 | 点击左侧 `参数设置` | 页面显示五个参数区域，实时视频不覆盖页面 | 查 `switchPage("settings")` 和 `setOverlayVisible(pageName === "home")`。 |
| 参数交互 | 开发板屏幕 | 点击参数 `+/-`、`切换`、`应用参数`、`恢复默认` | 参数值、摘要和底部提示条变化 | 查 `changeSettingValue()` 和 `settingsApplyAction()`。 |
| 告警页入口 | 开发板屏幕 | 点击左侧 `告警维护` | 页面显示当前告警、设备健康、告警历史和处理建议 | 查 `switchPage("alarm")`、`alarmPageVisible`。 |
| 告警操作 | 开发板屏幕 | 点击 `确认`、`清故障`、`刷新状态`、`保存诊断` | 告警状态或历史记录更新，底部提示条显示处理结果 | 查 `handleAlarmAction()` 和 `alarmHistoryModel.insert()`。 |
| Overlay 隐藏 | 开发板屏幕 | 进入参数页/告警页再返回首页 | 功能页不被视频覆盖，返回首页后实时视频恢复 | 查 `setOverlayVisible(pageName === "home")` 和 overlay `VISIBLE` 命令。 |
