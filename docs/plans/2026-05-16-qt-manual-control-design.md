# Qt 手动控制界面设计

## 目标

| 项目 | 设计结论 |
|---|---|
| 页面名称 | `手动控制` |
| 目标屏幕 | STM32MP157 7 寸 RGB LCD，固定 1024x600 |
| 所属程序 | `20_uvc_camera/qt_camera_display/` Qt Quick 工业检测主界面 |
| 核心定位 | 给调试、联调、演示和故障恢复使用，不替代自动检测主流程 |
| 控制边界 | MP157 只负责界面、状态展示和高层命令；传送带 PWM、机械臂舵机、急停、限位和联锁仍由 STM32F4 负责 |
| 第一版范围 | 先实现可进入的手动控制页、模拟状态、命令日志和安全交互；真实串口命令在后续 `MotionController` 接入 |

## 设计原则

| 原则 | 说明 |
|---|---|
| 安全优先 | 手动页不能绕过 F4 直接驱动硬件；急停、限位、故障态下的动作按钮必须禁用或提示禁止执行。 |
| 与主界面合并 | 复用现有左侧导航、顶部状态栏、底部提示条和深色工业界面风格，不单独新建一个 Qt 程序。 |
| 先 UI 后实控 | 第一阶段只做页面、状态和命令日志，避免在 F4 串口控制器未稳定前引入危险动作。 |
| 可答辩 | 页面要能清楚展示系统分层：MP157 负责人机交互和视觉，F4 负责实时执行和安全闭环。 |
| 可扩展 | QML 回调先集中到 helper 函数，后续只需要把 helper 接到 C++ `motionController`，不重写页面布局。 |
| 不遮挡视频层 | KMS overlay 模式下进入手动页时隐藏实时视频 plane；返回首页时恢复视频，避免 overlay 覆盖手动面板。 |

## 页面结构

| 区域 | 建议内容 |
|---|---|
| 顶部状态栏 | 延续现有相机、F4、机械臂、背光、云端状态；后续 F4 接入后显示真实在线和故障状态。 |
| 左侧导航栏 | `首页`、`历史记录`、`统计分析`、`手动控制`、`参数设置`、`告警维护`。当前 `手动控制` 需要从占位按钮变成真实页面入口。 |
| 中间主控制区 | 传送带、机械臂、光源、检测辅助四个控制分区。 |
| 右侧安全状态区 | F4 在线状态、自动/手动模式、急停、限位、机械臂回零、最近 ACK、最近错误码。 |
| 底部命令日志 | 最近 5 到 8 条手动命令，显示时间、命令名称、目标、结果和禁止原因。 |
| 底部提示条 | 复用现有 `storageState` / toast 风格，显示手动命令执行反馈。 |

## 控件设计

| 模块 | 控件 | 第一版行为 | 后续真实命令 |
|---|---|---|---|
| 模式切换 | `自动` / `手动` 分段按钮 | 切到手动时更新页面状态并记录日志；切回自动时提示先停止手动动作 | `CMD_START_AUTO`、`CMD_STOP` 或专用模式命令 |
| 传送带 | 正向点动、反向点动、停止、速度档位 | 只更新模拟状态和日志；停止按钮始终可点 | `CMD_MANUAL_AXIS`、`CMD_SET_BELT` |
| 机械臂 | 回零、待机位、抓取测试、放良品、放坏品 | 急停或未回零时禁用抓取/放置类动作 | `CMD_GO_HOME`、`CMD_SORT_REQUEST` 或动作组命令 |
| 执行器 | 夹爪开、夹爪关 | 更新夹爪模拟状态 | `CMD_MANUAL_AXIS` 的执行器设备字段 |
| 光源 | 背光常亮状态、上方补光开关、亮度档位 | 背光源按硬件事实一直开启，只允许调试补光和亮度显示 | 后续按硬件实际归属接 F4 或 MP157 GPIO |
| 检测辅助 | 保存当前帧、手动标记 GOOD/BAD/UNCERTAIN | 保存当前帧复用已有 `storageController.saveCurrentFrameToSdCard()`；标记只写界面状态 | 后续写入检测记录或复核结果 |
| 安全维护 | 清故障、刷新状态 | 第一版只记录日志；真实清故障必须二次确认 | `CMD_RESET_ALARM`、`STS_SENSOR`、`STS_SYS_STATE` |

## 数据与状态契约

| 状态字段 | 类型 | 来源 | 用途 |
|---|---|---|---|
| `manualPageVisible` | QML bool | `activePage === "manual"` | 控制手动页显隐。 |
| `manualMode` | QML bool | 页面按钮，后续来自 F4 状态 | 控制手动动作按钮是否可用。 |
| `manualBeltState` | string | 页面动作，后续来自 F4 ACK | 显示传送带停止、正向点动、反向点动。 |
| `manualArmState` | string | 页面动作，后续来自 F4 状态 | 显示机械臂待机、回零中、抓取测试等状态。 |
| `manualLightState` | string | 页面动作，后续来自光源控制器 | 显示背光和补光状态。 |
| `manualSafetyState` | object/string | 第一版模拟，后续来自 `STS_SENSOR` | 显示急停、限位、故障和回零状态。 |
| `manualCommandLog` | QML ListModel | 页面 helper 追加 | 显示最近命令和结果，便于现场联调。 |
| `manualLastAckText` | string | 第一版模拟，后续来自 F4 ACK | 右侧状态区显示最近响应。 |

## 页面切换契约

| 项目 | 契约 |
|---|---|
| `switchPage()` | 允许 `manual`，同时保留 `home`、`history`、`stats`。 |
| Overlay 可见性 | KMS overlay 模式下仅 `home` 显示视频，`history`、`stats`、`manual` 均隐藏视频 plane。 |
| 首页控制按钮 | 现有开始、暂停、继续、停止仍归首页自动流程使用，不和手动页动作混在一起。 |
| 手动页返回 | 点击返回首页后恢复实时画面，手动模拟状态保留，命令日志不清空。 |

## 安全交互

| 场景 | 界面行为 |
|---|---|
| 未进入手动模式 | 传送带和机械臂动作按钮置灰，只允许刷新状态、保存当前帧和进入手动。 |
| 急停按下 | 所有运动类按钮禁用，只保留停止、刷新状态和清故障入口。 |
| F4 离线 | 不允许发送真实动作命令；第一版显示 `F4待接入`，后续显示串口超时。 |
| 机械臂未回零 | 抓取测试、放良品、放坏品禁用，引导先执行回零。 |
| 自动流程运行中 | 进入手动页时提示先停止自动流程；后续接入时先下发停止自动命令再允许手动。 |

## 第一版与后续边界

| 阶段 | 内容 |
|---|---|
| 第一版 | 实现页面入口、布局、模拟状态、命令日志、安全置灰、保存当前帧复用、静态契约测试和文档更新。 |
| 第二版 | 新增 C++ `MotionController`，封装串口帧发送、ACK 等待、超时和错误文本。 |
| 第三版 | 接入 F4 `STS_SYS_STATE`、`STS_SENSOR`、`ACK`、`STS_SORT_RESULT`，把模拟状态替换为真实状态。 |
| 第四版 | 加入参数设置页，与手动页共享速度、动作组、光源亮度等参数，但仍由 F4 做最终限幅和联锁。 |

## 验收方式

| 测试目标 | 执行位置 | 命令/动作 | 预期输出/现象 | 失败时排查 |
|---|---|---|---|---|
| 静态契约 | 本地仓库 | `./test_qt_kms_overlay_assets.sh` | 输出 `PASS: Qt KMS overlay assets contract` | 检查 `manualPageVisible`、`manualCommandLog`、`id: manualPage` 等标记是否存在。 |
| 页面入口 | 开发板屏幕 | 点击左侧 `手动控制` | 进入手动控制页，实时视频不覆盖页面 | 检查 `switchPage("manual")` 是否允许，检查 overlay `VISIBLE 0` 命令。 |
| 安全置灰 | 开发板屏幕 | 不进入手动模式时点击运动按钮 | 运动动作不可执行，并提示需进入手动模式 | 检查按钮 `enabled` 条件和 `handleManualAction()` 的保护分支。 |
| 命令日志 | 开发板屏幕 | 切手动、点动传送带、停止、机械臂回零 | 日志按最新在前显示命令时间、目标和结果 | 检查 `manualCommandLog.insert(0, ...)` 和日志数量裁剪。 |
| 保存当前帧 | 开发板屏幕和 SSH | 在手动页点击 `保存当前帧`，再查 `/mnt/sdcard/images/uvc_*.jpg` | JPG/PNG 生成并复用现有 COS 上传历史 | 检查 `storageController.saveCurrentFrameToSdCard()` 和 SD 卡挂载。 |
| 返回首页 | 开发板屏幕 | 手动页点击返回首页 | 实时视频恢复，首页控制区正常 | 检查 `setOverlayVisible(pageName === "home")`。 |
